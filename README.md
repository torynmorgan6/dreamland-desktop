# Oraku desktop app

Installer and automatic updates for the Oraku desktop app: live draft help, build import, game uploads and stats next to the League of Legends client. Site: https://oraku.dev

Download the latest **[OrakuSetup.exe](https://github.com/torynmorgan6/dreamland-desktop/releases/latest/download/OrakuSetup.exe)** from Releases. Installed apps update themselves.

Windows may say it's from an unknown publisher: click **More info**, then **Run anyway**.
